# Baúl de Ingeniería

Aplicación Streamlit para consultas técnicas documentadas de Catastro
Multipropósito y Geodesia en Colombia. Puede usar Ollama local o conectarse a
los dos agentes OpenCode desde Streamlit Community Cloud. El despliegue remoto
requiere un servidor OpenCode HTTPS y secretos configurados.

Consulta [LEAME.md](LEAME.md) para instalación, configuración segura de
credenciales y despliegue. Fuentes oficiales consultadas:

- [Catastro](insumos/catastro_fuentes.txt)
- [Geodesia](insumos/geodesia_fuentes.txt)
- [Guía de insumos](insumos/README_fuentes.md)
